# Changelog

## Unreleased

Servlo starts here.

Servlo is a fork and inherits an engine, but it is a different product with a
different target, so it does not inherit the upstream release history. Those
entries described releases of a local development tool for Linux and macOS;
restating them under the Servlo name would claim releases Servlo never made.
The upstream history remains in this repository's git history, and the fork and
its link are stated in `README.md`.

The first Servlo release will be listed here.
