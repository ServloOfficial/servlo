# Changelog

## Unreleased

Servlo starts here.

Servlo is a fork of [Lerd](https://github.com/lerd-env/lerd) and inherits its
engine, but it is a different product with a different target, so it does not
inherit Lerd's release history. Lerd's changelog described releases of a local
development tool for Linux and macOS; restating those entries under the Servlo
name would claim releases Servlo never made. The upstream history remains in
this repository's git history and in the upstream project.

The first Servlo release will be listed here.
