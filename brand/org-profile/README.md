THE FREE, SELF-HOSTED CONTROL PANEL FOR PRODUCTION PHP SERVERS
</p>

---

Point a droplet at [**Servlo**](https://github.com/ServloOfficial/servlo) and run
your PHP sites from a browser. Add a site from a ZIP, a Git clone, a folder you
already have, or a one-click app. Give it a domain, click **Get SSL**, and deploy
it. Toggle MySQL or Redis on. Sleep, because the backups are tested by restoring
them rather than assumed.

It is the cPanel and Forge niche, except it runs on **your** server, costs
nothing, has no paid tier, and phones home to nobody.

```bash
curl -fsSL https://raw.githubusercontent.com/ServloOfficial/servlo/main/install.sh | bash
```

Ubuntu 24.04 LTS, rootless Podman, systemd, no Docker daemon, and no permanent
root process. MIT licensed.
